# 平台运动预测驱动的双臂内部力前馈调节——仿真

对应研究计划第 3–5 步：用最小仿真验证“预测误差 + 有限调力能力 → 可行边界”的理论结果，再扩展到完整对比实验。

## 快速开始

```bash
pip install -r requirements.txt
pytest
python -m experiments.exp01_feasibility_map
```

结果输出到 `results/`。

## 符号

| 代码 | 含义 | 论文符号 |
|---|---|---|
| `m, mu, g` | 质量、摩擦系数、重力加速度 | |

| `q0, q1` | 静止 / 阶跃后的 q | 待对齐 |

## 当前模型的局限（写论文时如实说明）

- 只考虑平台平移；转动带来的转矩项 M 未建模（传入非零 M 会报错）。
- 两点夹持、切向力平分、库仑摩擦。
- `theory.py` 只覆盖“单次阶跃 + 名义前馈”，不涉及闭环稳定性。
