## 本文方法：随预测可信度变化的安全余量

预测器除了给出预测 (Â, t̂)，还给出误差界 (δ̄, Δt̄) 表示可信度。`adaptive_feedforward` 据此设两类余量：

- 幅值余量：目标力 T = clip((1+margin) · q_w, f_max)，q_w 是界内最坏需求；
- 时刻余量：力到位时刻提前到 t̂ − Δt̄。

δ̄ = Δt̄ = 0 时退化为名义前馈。若 f0 ≥ q0、T 未被 f_max 截断且 t_cmd ≥ 0，则界内任意误差都不滑（开环、单次阶跃结论，证明见 `sim/theory.py` 文档）。

实验 2 结果（默认参数，每级 200 个界内均匀采样）：名义前馈的滑动率随误差界放宽升到 41%；固定保守余量和本文方法都没有滑动，
但本文方法的平均峰值力随可信度提高而下降（δ̄ = 0.05 时约 8.9 N，固定保守为 12.0 N），只在最低可信度时与固定保守相同。

## 当前模型的局限（写论文时如实说明）

- 只考虑平台平移；转动带来的转矩项 M 未建模（传入非零 M 会报错）。
- 两点夹持、切向力平分、库仑摩擦。
- `theory.py` 只覆盖“单次阶跃 + 前馈（名义 / 自适应余量）”，不涉及闭环稳定性。
- 本文方法的鲁棒保证（`robust_guarantee`）以“预测器给出的误差界正确”为前提；界本身估错（真实误差超界）时没有保证，这一情况留给第 5 步的误差放大压力测试。可信度如何从预测器得到（置信区间、历史残差等）尚未建模，目前直接给定 (δ̄, Δt̄)。
- 目标力被 `f_max` 截断时只报告“无保证”，没有不可行处理策略（第 4 步待做）。
- 仿真步长 dt = 1 ms 造成约一个步长的时刻离散误差：实验 2 中理论/仿真不一致的样本都离时刻边界不到 1 ms。
